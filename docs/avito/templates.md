# ZAPKIT: шаблоны и рабочие таблицы для Авито

Приложение к [плану запуска](launch-plan.md). Копируйте и подставляйте свои данные.

## Описание магазина

> **ZAPKIT — ремонт в одной коробке.**
>
> Собираем наборы запчастей под конкретную работу на вашей машине: ТО, тормоза, подвеска, ГРМ. Внутри всё до последнего болта и прокладки, плюс карта ремонта с видеоинструкцией.
>
> - **Подбор по VIN.** Если по нашему подбору деталь не подошла, вернём деньги.
> - **Не хватило детали по нашей вине** — довезём бесплатно.
> - **Перед отправкой присылаем фото собранного кита.**
> - Отправляем СДЭКом каждый вечер до 20:00.
>
> Hyundai Solaris, Kia Rio, VW Polo, Haval Jolion, Haval F7, Chery Tiggo, Geely Coolray. Не нашли свою машину? Напишите в чат, соберём кит под неё.

## Шаблон объявления-кита

### Заголовок

Формула: **Название кита + марка и модель + мотор или ключевое содержимое**. На Авито заголовок ограничен ~50 символами, лимит проверяйте при создании.

| Хорошо | Плохо |
|---|---|
| `ТО-кит Hyundai Solaris 1.6: масло и 3 фильтра` | `Комплект!!! Недорого!!!` |
| `Тормоз-кит перед Kia Rio 4: диски и колодки` | `Тормоза на Киа` |
| `ГРМ-кит Skoda Rapid 1.6 CWVA: ремень, помпа` | `Ремень ГРМ оригинал` |
| `Стабилизатор-кит VW Polo: стойки и втулки` | `Стойки` |

### Главное фото

Карточка по образцу `avito/png/kit-01-to-solaris-1-main.png`: логотип, тип кита, модель и список содержимого. Вторым фото ставьте **реальное фото собранной коробки**, третьим — содержимое, разложенное рядом.

### Описание

```
Всё для <работы> на <марка модель мотор годы> в одной коробке.
Подберём по VIN: пришлите VIN в чат, проверим каждую позицию.

Что внутри:
— <деталь 1>, <бренд>, <номер>
— <деталь 2>, <бренд>, <номер>
— <крепёж / прокладки / смазка>
— Карта ремонта с QR-видеоинструкцией

Гарантии ZAPKIT:
— Не хватило детали по нашей вине — довезём бесплатно.
— Не подошло по нашему подбору — вернём деньги и оплатим обратную доставку.

Кит выгоднее, чем покупать детали по отдельности.
Есть вариант без масла, а любую позицию можно заменить на оригинал: напишите в чат.

Отправляем СДЭКом каждый вечер до 20:00. Перед отправкой пришлём фото собранной коробки.
Доставка по всей России через Авито Доставку. Только новые детали.

ZAPKIT — ремонт в одной коробке.
```

**Правила:**
- **Указывайте бренд каждой детали.** Никогда не пишите «оригинал», если это аналог.
- Никаких телефонов, ссылок и названий других площадок: за это Авито блокирует.
- Синонимы вписывайте естественно («комплект ТО», «набор для ТО», «Солярис»), без списков ключевых слов.
- Один кит, одно объявление. Разные модели — разные объявления, дубли не делайте.

### Поштучное объявление (для трафика)

Заголовок: `Колодки передние Kia Rio 4 <бренд>`. В конце описания добавьте: «Нужно заменить и диски? Есть **Тормоз-кит**: диски, колодки, смазка и очиститель в одной коробке, выгоднее».

## Карта ремонта (вкладыш в коробку)

```
ZAPKIT · <ТИП КИТА>
<Марка Модель Мотор> · VIN: <последние 6 символов>

☐ <деталь 1> — <бренд> <номер>
☐ <деталь 2> — <бренд> <номер>
☐ <крепёж / прокладки / смазка>

[QR] Видео: как сделать эту работу

Всё на месте? Будем рады отзыву на Авито — он очень помогает.
Чего-то не хватает? Напишите нам в чат Авито, довезём бесплатно.
```

QR ведёт **на видеоинструкцию**, а не в магазин. Покупать мимо Авито не зазываем.

## Скрипты для чата

### Первое сообщение (в течение 5 минут)

> Здравствуйте! Это ZAPKIT, собираем запчасти наборами под конкретный ремонт. Пришлите, пожалуйста, VIN: 17 символов, он есть в СТС. Проверю каждую деталь кита под вашу машину. Если по нашему подбору что-то не подойдёт, вернём деньги.

### Предложение

> Под ваш VIN всё подходит. В ките:
> — <деталь 1> (<бренд>)
> — <деталь 2> (<бренд>)
> — <крепёж, смазка>
> — карта ремонта с видео
>
> Итого <цена> ₽. По отдельности вышло бы около <цена + 5%> ₽. Любую позицию могу заменить на оригинал, это +<разница> ₽. Отправим СДЭКом ближайшим вечером, перед отправкой пришлю фото собранного кита. Оформляем?

### Покупатель спрашивает одну деталь

> Могу продать отдельно за <цена> ₽. Но обычно вместе с <деталь> меняют <ещё детали>. Для этого есть **<Тип>-кит**: всё нужное плюс крепёж в одной коробке за <цена> ₽, выгоднее, чем по отдельности. Какой вариант удобнее?

### «Почему под заказ?»

> Мы не держим склад, поэтому цены ниже, чем в магазине. Детали приходят к нам от дистрибьютора за 1 день, мы проверяем каждую, собираем кит, присылаем вам фото и сразу отправляем.

### «Дорого»

> Понимаю. Могу собрать кит на более доступных брендах за <цена> ₽, разница в <ресурсе / материале>. Или уберу масло, если у вас своё: будет <цена> ₽.

### «Это оригинал?»

> В описании у каждой детали указан бренд. Сейчас в ките <бренды>: это проверенные производители, некоторые из них делают детали и для конвейера. Любую позицию можно заменить на оригинал с логотипом марки, это будет +<разница> ₽.

### Отправлено / доставлено

> Ваш кит уже плывёт 🐋 Трек-номер: <…>

> Кит приплыл! 🐋 Если будут вопросы по ремонту, пишите. Когда всё соберёте, оставьте, пожалуйста, отзыв: он очень помогает небольшому магазину.

### Если чего-то не хватило или не подошло

> Извините, это наша ошибка. Недостающую деталь довезём бесплатно (или вернём деньги, как вам удобнее). Отправлю сегодня же.

## Предложение для таксопарков

> **ТО-кит по подписке для вашего парка.**
>
> - Собираем ТО-киты (масло, фильтры, шайба пробки) под каждую машину парка по VIN.
> - Привозим по графику, до того как подойдёт срок ТО. Механик не ищет запчасти, машина не простаивает.
> - Оплата по счёту, закрывающие документы, фиксированная цена на месяц.
> - Не хватило детали — довезём бесплатно в тот же день.
>
> Пробный месяц: киты на 5 машин со скидкой 5%.

Искать таксопарки и службы доставки нужно через 2ГИС и Яндекс Карты, а не через клиентов с Авито.

## Отбор ассортимента

Задача: собрать **матрицу первых 50 китов**, которые будут продаваться.

1. **Модели:** 10 из плана ([п. 2.2](launch-plan.md#22-матрица-на-старт)). У каждой 1–2 самых массовых мотора.
2. **Киты на модель:** ТО-кит, тормоз-кит перед, стабилизатор-кит, сезонный кит, ГРМ- или охлаждение-кит.
3. **Спрос:** число объявлений и продавцов в поиске Авито по вашему региону и объём запросов в Яндекс Вордстате («то solaris», «колодки rio 4»).

## Метрики на неделю

| Неделя | Объявлений (киты / шт.) | Просмотры | Расход на просмотры, ₽ | Контакты | Просмотр → контакт, % | Заказы | Из них киты | Выручка, ₽ | Валовая прибыль, ₽ | Все расходы Авито, ₽ | Чистая прибыль, ₽ | CPO, ₽ | Ср. время ответа | «Довезём» / возвраты | Рейтинг |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | | | | | | |

**Правила чтения:**
- **CPO** (все расходы на Авито / число заказов) должен быть **меньше половины валовой прибыли с заказа**.
- Просмотр → контакт < 2%: плохие заголовок, фото или цена.
- Доля китов < 40%: в чате чаще предлагайте кит вместо одной детали.
- Больше 3% заказов с «довезём»: проверяйте сборку, скорее всего, ошибка в карте кита.
- Объявление набрало 300+ просмотров и ни одного контакта: переделать или снять.
