# ВПОРУ: шаблоны и рабочие таблицы для Авито

Приложение к [плану запуска](launch-plan.md). Копируйте и подставляйте свои данные.

---

## Описание магазина

> **ВПОРУ: новые запчасти для Mercedes-Benz**, легковых, Sprinter и Vito.
>
> - **Подбор по VIN с гарантией.** Если по нашему подбору деталь не подошла, вернём деньги и оплатим обратную доставку.
> - **На каждый запрос 3 варианта:** оригинал, OEM-производитель, бюджетный аналог.
> - **Перед отправкой присылаем фото детали** с артикулом.
> - Отправка 1–2 дня, доставка по всей России через Авито.
>
> Напишите в чат, ответим за несколько минут (ежедневно 9:00–21:00).

## Шаблон объявления

### Заголовок

Формула: **Что + (ось/сторона) + марка + кузов + (мотор/бренд)**. На Авито заголовок ограничен ~50 символами, лимит проверяйте при создании. Покупатели ищут по кузову (W213) и по номеру детали, поэтому оба должны быть в объявлении.

| Хорошо | Плохо |
|---|---|
| `Колодки тормозные передние Mercedes W213` | `Колодки!!! Недорого!!! Все модели` |
| `Комплект ТО Mercedes W213 E200 M264` | `Запчасти Мерседес` |
| `Пневмостойка передняя Mercedes W222` | `Пневмостойка оригинал качество` |
| `Цепь ГРМ комплект Mercedes M271` | `Цепь` |

### Описание

```
Подберём по VIN: пришлите VIN в чат. Если по нашему подбору деталь не подошла,
вернём деньги и оплатим обратную доставку.

Деталь: Колодки тормозные передние
Производитель: <бренд>, номер производителя: <номер>
Оригинальный номер Mercedes-Benz (OEM): <A000…>
Подходит: Mercedes-Benz E-класс W213 (<годы>), <другие кузова>.
Точную совместимость проверяем по VIN перед оплатой.

Есть 3 варианта:
— Оригинал Mercedes-Benz: <цена> ₽
— <OEM-бренд>, качество конвейерной поставки: <цена> ₽ (это объявление)
— Бюджетный аналог: <цена> ₽
Напишите, какой нужен, или спросите совета.

Срок: под заказ, отправка через 1–2 дня. Перед отправкой пришлём фото детали с артикулом.
Доставка по всей России через Авито Доставку. Только новые детали.

ВПОРУ: запчасти для Mercedes-Benz.
```

**Правила:**
- Пишите «качество конвейерной поставки» только если бренд **действительно** поставляет эту деталь на конвейер Mercedes. Не уверены, пишите просто «качественный аналог».
- Никаких телефонов, ссылок и названий других площадок: за это Авито блокирует.
- Синонимы вписывайте естественно («тормозные колодки», «Мерседес Е-класс»), без списков ключевых слов.
- Один товар, одно объявление. Не дублируйте одно и то же.

### Фото

1. Главное фото: деталь на светлом нейтральном фоне, крупно.
2. Упаковка с видимым артикулом и брендом.
3. Для комплектов ТО: всё содержимое вместе на одном фото.
4. Без чужих водяных знаков. Фото поставщика используйте, только если он это разрешает.

## Скрипты для чата

### Первое сообщение (в течение 5 минут)

> Здравствуйте! Это ВПОРУ, запчасти для Mercedes-Benz. Пришлите, пожалуйста, VIN: 17 символов, он есть в СТС. Подберу точно под вашу машину и предложу 2–3 варианта по цене. Если по нашему подбору деталь не подойдёт, вернём деньги.

### Предложение

> Под ваш VIN подходит номер <A…>. Варианты:
> 1) Оригинал Mercedes-Benz: <цена> ₽
> 2) <OEM-бренд>: <цена> ₽. **Оптимально по цене и качеству**
> 3) Бюджетный аналог: <цена> ₽
>
> Отправим через 1–2 дня, перед отправкой пришлю фото. Какой вариант оформить?

### «Почему под заказ?»

> Мы не держим склад и не платим аренду, поэтому цены ниже, чем в магазине. Деталь приходит к нам от дистрибьютора за 1 день, мы сверяем артикул, присылаем вам фото и сразу отправляем.

### «Дорого»

> Понимаю. Можно взять вариант подешевле: <аналог> за <цена> ₽. Разница в <ресурсе / материале / шумности>. Для вашей машины и пробега я бы взял вариант 2, он оптимальный. Решать вам.

### «Это оригинал?»

> Вариант 1 — оригинал с логотипом Mercedes-Benz. Вариант 2 — деталь от <бренд>: этот производитель делает такие детали и для конвейера, но без звезды на коробке, поэтому она дешевле. Вариант 3 — аналог попроще. Подделок не продаём, работаем только с проверенными дистрибьюторами.

### «Можно дешевле?»

> На одну деталь цена уже минимальная. Если берёте комплектом (<колодки + диски / всё ТО>), сделаю скидку 5%.

### После продажи

> Спасибо за заказ! Трек-номер: <…>. Если будут вопросы по установке, пишите, подскажем. Когда получите и всё подойдёт, оставьте, пожалуйста, отзыв: он очень помогает небольшому магазину.

### Если деталь не подошла по нашему подбору

> Извините за неудобство, это наша ошибка. Оформим возврат, обратную доставку оплатим мы. Если хотите, сразу подберу правильную деталь и отправлю вне очереди.

## Отбор ассортимента

Задача: найти **первые 300 позиций**, которые будут продаваться, а не просто висеть и тратить деньги на просмотры.

1. **Модели.** 10 кузовов из [плана, п. 1.5](launch-plan.md#15-с-чего-начать-ассортимент-mercedes). У каждого 1–2 самых массовых мотора, всего 15–20 связок.
2. **Группы на связку:** комплект ТО, колодки и диски на обе оси, 4–6 позиций подвески, 2–3 «болячки».
3. **Спрос:** смотрите число объявлений и продавцов в поиске Авито по вашему региону и объём запросов в Яндекс Вордстате (например, «колодки w213»).
4. **Цена:** закупка у поставщика против медианной цены на Авито. **Берите позицию, если при медианной цене маржа ≥ 25%.**
5. Заполните таблицу:

| Модель | Мотор | Группа | Деталь | OEM-номер | Варианты (ориг./OEM/аналог) | Закупка, ₽ | Медиана Авито, ₽ | Наша цена, ₽ | Маржа, % | Спрос (Вордстат) | Конкурентов |

## Анализ конкурентов

Один вечер: 10 ходовых артикулов и 5 запросов вида «колодки W213», поиск в вашем регионе.

| Продавец | Тип (магазин / перекуп / разборка) | Рейтинг и число отзывов | Время ответа | Объявлений | Цена арт. 1 | Цена арт. 2 | … | Доставка | Фото (свои / стоковые) | Гарантии | Что взять себе |
|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | |

**На что смотреть:** кто отвечает быстрее всех (напишите им сами, как покупатель), у кого лучшие отзывы и за что хвалят, чего не хватает всем (обычно подбора и гарантий). Это и есть ваше преимущество.

## Метрики на неделю

| Неделя | Объявлений | Просмотры | Расход на просмотры, ₽ | Контакты | Просмотр → контакт, % | Заказы | Контакт → заказ, % | Выручка, ₽ | Валовая прибыль, ₽ | Все расходы Авито, ₽ | Чистая прибыль, ₽ | Цена заказа (CPO), ₽ | Ср. время ответа | Возвраты | Рейтинг |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | | | | | | |

**Правила чтения:**
- **CPO** (все расходы на Авито / число заказов) должен быть **меньше половины валовой прибыли с заказа**. Если больше, чините объявления, а не увеличивайте бюджет.
- Просмотр → контакт < 2%: плохие заголовок, фото или цена.
- Контакт → заказ < 15%: медленный ответ, цена выше рынка или нет нужного варианта.
- Объявление набрало 300+ просмотров и ни одного контакта: переделать или снять.
